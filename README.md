# WordChain AI

---

## 프로젝트 개요

OpenAI API를 활용한 콘솔 기반 끝말잇기 게임입니다.

AI가 단어를 생성하고, 생성된 단어와 사용자 입력 모두를 동일한 검증 절차를 거쳐 게임을 진행합니다. 단순히 LLM이 생성한 결과를 그대로 사용하는 것이 아니라, JSON 형식 검증과 게임 규칙 검증을 별도로 수행하도록 설계해 안정성을 높였습니다.

* 개발 형태: Python 기반 콘솔 애플리케이션
* 개발 인원: 1인
* 개발 기간: 약 2일

※Windows 환경에서만 작동합니다.

```
src/

 ├── utils.py

```

### 역할

* **Game**: 게임 진행 및 전체 흐름 관리
* **GameState**: 현재 단어, 사용 단어, 실수 횟수 등 게임 상태 관리
* **Validator**: 끝말잇기 규칙 및 게임 규칙 검증
* **OpenAIClient**: OpenAI API 호출 및 JSON 응답 처리
* **Prompt**: AI 생성 및 검증 프롬프트 관리
* **Utils**: 입력 타임아웃 등 공통 기능

---

## 주요 기능

* OpenAI 기반 끝말잇기 AI
* 표준국어대사전 일반 명사 여부 검증
* 두음법칙 지원
* 한방단어 허용/비허용 설정
* 11번째 단어부터 한방단어 허용 옵션
* 중복 단어 검증
* 사용자 입력 10초 제한
* AI 응답 JSON 검증
* AI와 사용자 모두 동일한 검증 로직 적용
* 실수 3회 허용(4회째 패배)

---

## 게임 규칙

* 표준국어대사전의 일반 명사만 사용할 수 있습니다.
* 두음법칙을 허용합니다.
* 한방단어는 설정에 따라 허용 여부가 결정됩니다.
* 허용 시에도 11번째 단어부터 사용할 수 있습니다.
* 잘못된 단어 또는 시간 초과는 실수로 처리됩니다.
* 실수는 3회까지 허용되며, 4번째 실수 시 패배합니다.

## 구현

### AI 단어 생성

OpenAI Responses API를 이용해 현재 단어와 사용된 단어 목록을 전달하고, 조건을 만족하는 단어를 JSON 형식으로 생성하도록 구현했습니다.

### 게임 상태 관리

게임 상태를 별도의 `GameState` 클래스로 분리하여 현재 단어, 사용 단어 목록, 실수 횟수, 게임 종료 여부 등을 한 곳에서 관리하도록 설계했습니다.

### 규칙 검증

모든 단어는 Validator를 통해 다음 순서로 검증합니다.

* 끝말잇기 규칙
* 두음법칙
* 중복 단어
* 표준국어대사전 일반 명사 여부
* 한방단어 여부
* 게임 옵션

사용자와 AI 모두 동일한 검증 절차를 사용하도록 구성했습니다.

### 사용자 입력 처리

사용자는 10초 이내에 단어를 입력해야 하며, 시간 초과 시 실수로 처리됩니다.

## 기술적 고민 및 개선점

### AI 응답의 신뢰성

LLM은 항상 올바른 형식으로 응답한다고 보장할 수 없기 때문에, JSON 파싱과 필수 필드 검증을 수행한 뒤에만 게임 로직으로 전달하도록 구성했습니다.

### AI 결과 재검증

AI가 생성한 단어 역시 사용자 입력과 동일한 검증 절차를 거치도록 구현했습니다. 이를 통해 존재하지 않는 단어나 규칙에 맞지 않는 단어가 게임에 사용되는 상황을 방지했습니다.

### 역할 분리

게임 진행(Game), 상태 관리(GameState), 규칙 검증(Validator), OpenAI 통신(OpenAIClient)의 책임을 분리하여 유지보수와 확장성을 고려했습니다.

### 한계

표준국어대사전을 직접 구축하지 않고 AI를 이용해 단어를 검증하는 방식이므로, 드물게 잘못된 판정이 발생할 가능성이 있습니다. 실제 서비스에서는 사전 데이터베이스를 구축하거나 외부 사전 API를 활용하는 방식이 더 적합하다고 생각합니다.
